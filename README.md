# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## About

Junteng Liu is a Ph.D. candidate in Computer Science at the Hong Kong University of Science and Technology (HKUST), NLP Group, advised by Prof. Junxian He.

## Site structure

- `_config.yml` - site-wide configuration (author info, social links, publication categories)
- `_pages/` - page content (About, Publications, CV)
- `_publications/` - one Markdown file per publication
- `_data/` - navigation and author data

## Build locally

Install dependencies and run Jekyll:

```bash
bundle install
bundle exec jekyll serve
```
